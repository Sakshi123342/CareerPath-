# CareerPath 🚀

CareerPath is a Django-based career guidance and student profile analysis project developed as a learning project.

It helps students explore suitable career options based on their education, interests, strengths, skills, and assessment results.

## ✨ Features

- 🏠 Professional Home Page
- 👤 Student Registration & Login
- 📋 Student Profile Management
- 🎓 Education Level Selection
- 🧠 Interest & Strength Analysis
- 📝 Career Aptitude Assessment
- 🤖 Profile Analysis
- 📊 Career Matching & Score
- 💼 Career Recommendations
- 📈 Career Comparison
- 🛠️ Skill Gap Analysis
- 🗺️ Career Roadmap
- 📚 Courses & Project Recommendations
- 📊 Student Progress Dashboard
- 🔐 Django Authentication
- 🤖 Gemini API Integration for AI-based features

## 🛠️ Technologies Used

- Python
- Django
- SQLite
- HTML
- CSS
- JavaScript
- NumPy
- Pandas
- Scikit-learn
- Django REST Framework
- Gemini API
